# Contributing to Warren Victor's Portfolio

Thank you for your interest in contributing!

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Open `index.html` in a browser to preview changes
4. Make your changes on a feature branch
5. Submit a pull request

## Guidelines

- **No personal information:** Never add mobile numbers, home addresses, or other private contact details.
- **Content accuracy:** Do not add or modify biographical facts without owner approval.
- **Design consistency:** Follow the existing dark glassmorphism design system (see [AGENTS.md](./AGENTS.md) for details).
- **Accessibility:** Ensure all changes maintain semantic HTML, alt text, and keyboard navigability.
- **No frameworks:** This is a plain HTML/CSS/JS project. Do not introduce build dependencies for the deployed site.

## Reporting Issues

Open an issue describing the problem, including:
- Browser and OS version
- Screenshot if visual
- Steps to reproduce
